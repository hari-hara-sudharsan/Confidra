# Confidra Ecosystem & Marketplace Guide

Confidra is not just a standalone application; it is the foundational platform for Confidential Decision Infrastructure. Our ecosystem allows organizations to modularize, share, and extend the core logic engine securely.

## Workflow & Policy Marketplace
The **Workflow Marketplace** is a centralized hub where organizations can discover and import pre-configured, peer-reviewed evaluation templates. 

For example, a university deploying a "Scholarship Evaluator" workflow can publish their schema (excluding sensitive proprietary thresholds) to the marketplace, allowing other educational institutions to inherit best practices securely.

## Plugin Framework & Connectors
Confidra supports secure extensions via the **Plugin Framework**. 
- **Enterprise Connectors**: Native integrations with Identity Providers (Okta), CRM platforms (Salesforce), and Cloud Storage providers.
- **Custom Plugins**: Developers can author secure plugins that interact with the TEE evaluation lifecycle, such as triggering a webhook to a proprietary legacy HR system once an AI decision is cryptographically anchored to the Flare blockchain.

## Organization Hubs
Every enterprise operating on Confidra receives a verified public **Organization Hub**. This profile acts as a public-facing portfolio showcasing their deployed Web3 infrastructure, published Developer APIs, and cryptographically proven Trust Certificates.
